# 分娩保障跨域结算

本项目提供分娩保障跨域结算的服务端领域基础。在住院分娩零自付、生育津贴直发和异地结算扩围的背景下，结算簿统一管理参保关系时段、人员类别、地区政策版本、基础服务包、并发症分组、费用明细、预授权、基金责任、个人支付、津贴申请和申诉。

## 目录

- `src/domain.js` 基础记录、金额（整数分）、参保关系、政策版本、就医案例、费用明细、预授权的定义与校验。
- `src/settlement.js` 结算引擎：政策版本选择、快照冻结、基础包/并发症/包外责任拆分、总额守恒校验、异地重算差异。
- `src/allowance.js` 津贴台账：幂等申请、业务号冲突停止支付、已到账津贴的冲正链。
- `src/appeal.js` 申诉台账：登记、办结与时限的故障顺延。
- `src/repository.js` 进程内仓库与结算簿存储（含幂等键与故障窗口）。
- `src/service.js` 应用服务：结算、例外审批、重算、津贴、故障恢复与说明接口。
- `contracts/` 现有输入契约与结算簿核心约束。
- `data/sample.json` 基础登记冒烟数据；`data/scenario.json` 完整结算场景。
- `tests/` 覆盖登记、结算、重算、津贴、例外、申诉、故障顺延与说明接口。

## 核心约束

- 结算冻结就医期间适用的政策快照，之后的政策更新不影响已生成的分录。
- 基础分娩与并发症费用按各自责任拆分；每笔费用的分录合计等于费用金额（总额守恒）。
- 服务包外费用不享受零自付，由个人承担。
- 异地重算只替换受影响分录，未受影响分录保持原编号与版本。
- 已到账津贴的追溯调整通过冲正链处理：支付 → 冲正 → 重发。
- 医院回调与申请重试凭幂等键返回原结果；同一业务号金额冲突时停止支付。
- 录入费用的人不得批准例外（职责分离）。
- 服务故障恢复后，待结算时限与申诉时限按故障时长顺延。

## 说明接口

- `explainCharge(chargeId)` 每笔费用为何由哪一方承担。
- `explainPolicyChange(caseId)` 政策更新改变了什么。
- `familyStatement(personId)` 家庭尚可获得哪些款项。
- `openDisputes(filter)` 是否存在未决争议。

## 运行

运行测试：`npm test`

检查源码：`npm run build`

验证样例：`npm run check:sample`

完整场景演示：`npm run demo`

项目只使用 Node.js 内置模块，不需要连接其他运行服务。
